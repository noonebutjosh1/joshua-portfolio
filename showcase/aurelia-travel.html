Aurelia Travel Co.

A boutique travel website built with Django templates and routed views, featuring curated journeys, a brand story page, and a server-rendered registration flow for trip enquiries.

Aurelia Travel Co. landing page preview

Curated Homepage

The landing page presents featured journeys, brand benefits, and travel statistics using Django-rendered content blocks.

About Storytelling

An About page communicates the company principles and milestones to make the travel brand feel established and trustworthy.

Registration Flow

The register page handles form submission through Django views and feeds back a submitted state without needing a separate frontend app.

Tech Stack

Python Django HTML5 CSS3 SQLite

This project runs as a local Django app, so it is shown here as a case study instead of a GitHub Pages live preview.

Run Locally

  1. Open `C:\Users\J.O.S.H.U.A\Desktop\django-tutorials\project5` in your terminal.
  2. Install Python and Django if they are not already available on your machine.
  3. Run `python manage.py runserver` from the project folder.
  4. Visit `http://127.0.0.1:8000/` in the browser to view the app.

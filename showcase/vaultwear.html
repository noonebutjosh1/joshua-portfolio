Local Demo (XAMPP)

Vaultwear

Dark-mode streetwear ecommerce project built with PHP and MySQL, featuring a storefront, product detail flow, session-based cart, checkout, and a protected admin dashboard for product and order management.

Back to Projects Run Locally
Vaultwear landing page preview

Storefront

Featured drops, product browsing, brand sections, and product detail pages with stock-aware actions.

Cart & Checkout

Session-backed cart updates, quantity management, checkout validation, and order confirmation flow.

Admin Workflow

Protected admin area for product uploads, inventory updates, and order management through a local dashboard.

Tech Stack

PHP MySQL PDO JavaScript HTML5 CSS3 XAMPP

This project is designed for a local XAMPP environment, so it is presented here as a case study rather than a GitHub Pages live demo.

Run Locally

  1. Place the project in `C:\xampp\htdocs\vaultwear`.
  2. Start Apache and MySQL from XAMPP.
  3. Create/import the `vaultwear` database using `database.sql`.
  4. Open `http://localhost/Vaultwear/` in the browser.
